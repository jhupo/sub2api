# Sub2API v0.2.11

## 上游 v0.2.4 集成

在本站 v0.2.10 基础上整合上游修复，保留独立支付来源、套餐额度、分组权限、渠道定价和 Codex 调度架构。

### OpenAI 与 Codex

- 修复瞬时 OAuth 429 被错误解释为长周期额度耗尽：窗口重置时间不能单独证明耗尽，需对应使用率达到 100% 或明确的配额重置信号。保留本站请求级重试及可配置冷却策略。
- 账号运行时冷却恢复加入版本证据：只有先观察到冷却持久化，再收到更新的恢复快照，才允许清除本地保护。旧快照、无关状态修改及先前冷却的恢复不能撤销新冷却。
- 修复 Chat 流取消时先关闭响应体可能拖延的问题；客户端取消后及时取消上游，并保留已观察到的用量和计费档位。
- WS 取消时丢弃本轮连接，保留结果穿过转发层到结算层。不再后台长时间排空，不因客户端取消换号重放或标记账号失败。

### Image 2.5

- 加入 gpt-image-2.5-flare、gpt-image-2.5-sunburst 的模型目录、白名单、映射、价格回退及图片调用链支持。
- OAuth 图片工具模型与 Responses 驱动模型分离；驱动默认 gpt-5.6-sol，可使用 SUB2API_IMAGES_MAIN_MODEL 覆盖。账号仍需具备对应上游模型权限。
- Images 接口缺少输出分类明细时将输出 token 归为图片；上游明确提供分类时尊重其数据，不对普通文本 Responses 套用该规则。
- 图片预扣纳入尺寸、数量和已知编辑输入，遵循实际生效的渠道定价、倍率与支付来源。按张计费仍按张，按 token 计费预留图文预算。
- 图片 base64 和预览事件不再触发文本输出窗口追加预扣；混合图文请求保留文本增量预算。

### 渠道、代理与管理

- 渠道配置通过 Redis 发布失效通知，重连后清理快照；构建过程使用版本校验，防止旧数据或旧错误覆盖新配置。服务退出时停止订阅。
- 修正备用代理为有向多对一关系，允许多个主代理共享备用代理。局部更新不再清空未提交的有效期和回退字段。
- 连续代理过期仍可继续回退，保留最初代理以便人工恢复；增加日期范围校验和列表响应校验。
- 系统日志使用独立保留周期，访问日志入库可选；告警、错误及审计日志保留原有索引规则。
- 修复账号菜单越界、停用分组无法解除关联、批量刷新失败项选择丢失及注册入口显示问题。
- 合入 Claude 单 token 探测、Antigravity 授权套餐信息保存和 Grok 不支持字段过滤修复，保护工具 schema、参数及结果不被递归误删。
- 更新 go-redis 至 9.22.0。

## 升级与边界

- 镜像：`ghcr.io/jhupo/sub2api:0.2.11`。二进制更新继续使用本仓库 Release。
- 本批次不新增 SQL 迁移，不转换 Redis 数据；备用代理关系使用已有字段和非唯一索引。升级更老版本仍会执行该版本间已有的迁移，建议常规备份。
- 无需删除数据库或缓存卷；不要使用 `docker compose down -v`。本次发布不执行任何生产服务器升级。
- 图片预扣是本地估算，不是上游保证的最大 token 数；最终费用以上游实际用量和本站定价为准。
- 客户端取消前未收到的最终上游用量无法凭空恢复，不以估算补写账单。未进行真实付费模型调用或生产压力测试。
- 详细提交映射与实现说明见 `docs/UPSTREAM_V024_INTEGRATION.md`。
