# Sub2API v0.2.12

## Gemini OAuth 额度与模型目录

- 通过账号 Token Provider 获取有效凭据，优先查询上游 retrieveUserQuotaSummary，保留实际返回的额度窗口、剩余比例和重置时间，不再从单个模型额度推断五小时额度。
- 只有额度汇总接口不受支持时才回退模型额度；401、403、429 和异常响应不再被解释为没有额度。429 不继续向其他入口重复探测。
- Gemini Antigravity 不再使用估算的每日 1500 次、每分钟 120 次作为调度额度门槛；已有上游限流和冷却处理继续生效。
- 模型目录采用首个成功的授权目录，不合并不同环境的目录；保留授权模型 ID 和思考变体。显式同步失败会返回错误，不把旧缓存冒充新目录。
- 管理页面和渠道监控展示同源额度窗口。模型白名单和自定义映射继续由管理员控制；明确指定但不可用的变体不静默降级。

## 官方标准价格与扣费

- 基础目录采用非促销的官方 Standard API 价格。Gemini 3.6 Flash 为每百万 token 输入 1.50 美元、输出 7.50 美元、缓存读取 0.15 美元，不套用临时五折优惠。
- 已知 Gemini 思考级别共用所属公开模型的价格卡；思考 token 按实际输出用量收费，不另乘思考级别倍率。现有管理员显式定价保留。
- Gemini 原生图片默认按输入、文本与思考输出、图片输出分别计费，避免按张默认路径漏计输入和思考。已有显式按张配置不被覆盖。
- Gemini 2.5 Flash 音频输入和缓存音频分别按官方音频单价计算，音频 token 是输入和缓存总数的子集，不重复累加。流式与非流式协议转换保留这两个用量分项。
- 既有强制缓存计费策略同步转换音频分项，避免缓存音频被按文本缓存单价结算。音频预扣只检查实际输入内容，不把工具定义中的 MIME 示例当成音频请求。
- 预扣纳入 Gemini 图片输出和音频输入估算；最终根据上游实际用量结算。用户专属或分组倍率作用于实际费用，账号统计倍率不会再次乘到用户账单。
- Gemini Antigravity 请求发送前校验可识别或显式配置的价格；未知内部 agent/GPT-OSS 模型需要配置计费映射或明确价格，不能根据名字猜成其他模型。
- 排队心跳已经发出时，缺价错误按对应 SSE 协议返回；原生 Gemini 流内错误保留 Google 错误结构并写入运维错误标记。
- 自定义模型别名的价格预检与最终结算共用明确的价格选择规则，遵守上游模型计费设置，不因别名看起来像另一模型而误套家族价格。

## 升级说明与边界

- 镜像为 ghcr.io/jhupo/sub2api:0.2.12；二进制使用本仓库 Release。
- 本次不新增数据库迁移，不改历史账单、余额、套餐剩余额度或 Redis 数据格式，不执行任何生产服务器操作。
- 保留已有渠道和分组定价、长上下文开关及高峰倍率。既有自定义价格并不会被自动改成官方价。
- 显式缓存存储时间、搜索工具费用和未知模型对应关系不能从普通 token 或显示名称推测。本次不新增这类推算收费。
- 预扣不是上游用量承诺；客户端取消前未收到的用量不能凭空恢复。回归测试不使用生产凭据，不执行真实付费推理。
- 本次发布聚焦 Gemini 额度、模型与计费；工作区中独立的 OpenAI 身份和调度修改不纳入本版本。

## 发布验证

- 独立导出的发布候选通过后端全量单元测试：`go test -work -p 1 -tags unit ./...`。

- 未执行真实付费推理或需要外部 PostgreSQL/Redis 的集成测试；以上验证不等于生产环境实测。
